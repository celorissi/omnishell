Documentação & Sobre o OmniShell Gateway
Visão Geral da Ferramenta

O OmniShell Gateway é uma solução portátil e centralizada para gerir conexões SSH remotas diretamente no browser com múltiplos painéis e suporte avançado a interações de terminal.

Guia Prático & Atalhos
  • Copiar Texto Selecionado: Selecione com o rato qualquer texto dentro do terminal e clique no botão de cópia rápida () no topo do painel correspondente para enviar diretamente para a sua área de transferência.
  • Colagem Segura (Botão Direito): Clique com o botão direito em qualquer terminal para abrir a caixa flutuante de colagem segura. Cole o seu bloco de comandos e verifique antes de enviar.
  • Reconectar (Ctrl + R): Pressione Ctrl + R no teclado dentro do terminal ativo para reiniciar instantaneamente a conexão.
  • Exportar Log de Sessão: Clique no botão de download () no cabeçalho do terminal para guardar todo o histórico num ficheiro `.txt` com timestamp.
  • Histórico Alargado (Buffer): Cada terminal dispõe de um buffer de 50.000 linhas para análise retroativa profunda de outputs e logs de routers/switches.
Segurança & Ociosidade

As sessões inativas são monitorizadas em tempo real. Caso ultrapasse o tempo limite configurado nas suas definições, a sessão SSH é encerrada automaticamente para proteger o acesso aos ativos corporativos.
