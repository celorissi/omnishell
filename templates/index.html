Documentação & Sobre o OmniShell Gateway
Visão Geral da Ferramenta

O OmniShell Gateway é uma solução portátil e centralizada para gerir conexões SSH remotas diretamente no browser com múltiplos painéis, abas rápidas no modo 1x1, painel lateral de Runbooks/Snippets organizados por categorias e interações avançadas de terminal.

Guia Prático & Atalhos
  • Abas no Modo Painel Único (1x1): Alterne entre sessões abertas usando a barra de abas no topo, o botão de alternância ou os atalhos Alt + 1..4 e Alt + Setas.
  • Runbooks por Categorias: Clique em Runbooks no topo direito para abrir o painel lateral. Organize seus grupos em pastas usando > ou / (ex: Cisco > Diagnóstico), dispare comandos individuais com 1 clique ou execute toda a sequência com Rodar Tudo.
  • Copiar Texto Selecionado: Selecione com o rato qualquer texto dentro do terminal e clique no botão de cópia rápida () no topo do painel correspondente.
  • Colagem Segura (Botão Direito): Clique com o botão direito em qualquer terminal para abrir a caixa flutuante de colagem segura.
  • Reconectar (Ctrl + R): Pressione Ctrl + R dentro do terminal ativo para reiniciar instantaneamente a conexão.
  • Exportar Log de Sessão: Clique no botão de download () no cabeçalho do terminal para guardar o histórico de 50.000 linhas em `.txt`.
Segurança & Ociosidade

As sessões inativas são monitorizadas em tempo real. Caso ultrapasse o tempo limite configurado nas suas definições, a sessão SSH é encerrada automaticamente para proteger o acesso aos ativos corporativos.
